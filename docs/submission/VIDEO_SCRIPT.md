## PPT 大纲（8 页）

1. **封面**：Mooncake KVCache 分层存储设计与性能优化（赛道 / 队伍 / 仓库链接）
2. **问题**：prefill 昂贵 → 以存换算；HBM 有限 → 空闲 DRAM 变现为二级缓存
3. **架构图**：vLLM connector → pybind11 → C++ 核心（分层存储 / 分片并发 /
   前缀预取 / 上游 Transfer Engine 接线）
4. **核心技术①**：S3-FIFO fast 层 + 纯 LRU slow 层 + 淘汰即降级（消融：no-demote 吞吐 −14%～−42%）
5. **核心技术②**：前缀感知多锚点链式预取 + O(1) 淘汰路径（回放 >400× 提速）
6. **结果**：命中率表（基线 0.462→0.519 等）+ 容量扩展曲线（1×→8× 单调 +10~24pp）
   + 端到端（TTFT p50 −71%、吞吐 +18.8%）
7. **工程质量**：22 项属性测试、三消毒器矩阵、clang-tidy 门禁、CI 全绿、可复现回放
8. **总结与展望**：3/4 trace 追平并略超模型参考；硬件基准框架已预留
