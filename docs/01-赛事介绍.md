# 赛事介绍

> 来源：[https://www.gitlink.org.cn/competitions/track2_2026Mooncake](https://www.gitlink.org.cn/competitions/track2_2026Mooncake)（赛事官网「赛事介绍」栏目）

**赛题背景**
随着大模型应用的普及，推理过程中的高计算资源消耗和 KVCache（键值缓存）的冗余存储成为关键瓶颈，导致推理成本高昂、吞吐量受限，尤其在长上下文场景中表现尤为突出。Mooncake 项目通过创新的以 KVCache 为中心的“PD 分离”架构（计算与存储解耦）和“以存换算”设计，将 KVCache 池化共享，结合高性能传输技术（如 eRDMA、GPUDirect）和分布式存储优化，实现跨实例的资源复用。
目前，Mooncake开源项目获得了4K+Star，吸引了龙蜥社区/阿里云/清华/月之暗面/蚂蚁/字节/趋境科技等多方100名社区贡献者参与。并且Mooncake已经支持了绝大多数的推理软件栈，如SGLang，vLLM，Dynamo，TensorRT-LLM，RTP，LMDeploy等，深度支持了推理框架的PD分离，Large EP，KVCache共享，RL更新等关键特性。

# 参赛规则须知
1. 参赛团队1-5人（名额不含指导老师，指导老师限1人），队员实名报名。
2. 每队设1名队长，即报名发起人，证书队员顺序以报名系统为准，队长排首位；换队长需重新报名。
3. 每人仅限担任一支队伍队长，可自由加入多支队伍；身兼多队队长获奖，仅发放最高金额奖项奖金。
4. 可跨单位组队，仅限最多2个不同单位组合参赛。
5. 初赛作品提交后，团队、导师、证书、奖金信息一律不予修改。
6. 获奖证书成员顺序固定，赛后不可调整。
7. 电子证书统一发放至队长CCF账号，队长需提前用报名手机号完成CCF官网账号注册，无需充值会员。
8. 如需了解更多规则，请见官网[赛程赛制](https://www.gitlink.org.cn/competitions/2026/schedule)页面中的【赛事规则】和【评审规则】。
