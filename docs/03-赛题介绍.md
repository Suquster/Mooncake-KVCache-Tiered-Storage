# 赛题介绍

> 来源：[https://www.gitlink.org.cn/competitions/track2_2026Mooncake](https://www.gitlink.org.cn/competitions/track2_2026Mooncake)（赛事官网「赛题介绍」栏目）

**赛题1：**
除了vLLM/SGLang之外，实现其他推理框架（Ollama/TRT-LLM）对于Mooncake PD分离框架的支持。
**赛题2：**
优化Mooncake Store吞吐性能，高可用功能和可扩展性等，优化SGLang HiCache+Mooncake Store性能。
**赛题3：**
基于Mooncake Transfer Engine，对NVLink，UB，UALink，CXL等传输性能进行优化
