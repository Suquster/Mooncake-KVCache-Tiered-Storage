# 参赛指南

> 来源：[https://www.gitlink.org.cn/competitions/track2_2026Mooncake](https://www.gitlink.org.cn/competitions/track2_2026Mooncake)（赛事官网「参赛指南」栏目）

**1、赛事报名**
**（1）参赛资格**
全球高校学生、科研人员、企业 / 独立开发者、开源爱好者，无国籍、年龄、职业限制。
**（2）组队规则**
- 团队规模：1-5 人（不含指导老师），设 1 名队长
- 指导老师：每队最多 1 名，仅提供指导，不参与核心创作
- 跨单位：最多支持 2 个不同单位组队
- 信息修改：截止 2026.7.10，逾期不可改
**（3）报名步骤**
在本页面点击“立即报名”按钮，进入报名界面，按照页面流程填写报名信息，报名参赛。
**2、赛事核心任务**
**开发基础：**
参赛作品须基于 Mooncake 开源项目（大模型推理与 KVCache 分离架构）进行开发，确保新增的优化或功能模块能够与现有分布式存储及调度系统平滑集成并正常运行。
**编码规范：**
严格遵循 Mooncake 开源项目的编码规范（以 C++ 和 Python 为主），代码可读性、可维护性、可扩展性良好。杜绝冗余代码、无效注释及潜在 bug，在涉及 RDMA 网络传输与并发操作的核心链路中需符合严谨的内存与线程安全标准。
**性能要求：**
开发的功能需满足大模型推理系统的高吞吐、低延迟等基础性能要求。作品应当能够有效提升 KVCache 的命中率与复用率，或显著优化跨节点间的显存/内存 I/O 与网络传输效率。
**兼容性要求：**
支持主流 Linux 操作系统（如 Ubuntu 等发行版），兼容主流的 AI 算力硬件环境（如 Nvidia GPU 等），并需与当前主流的开源推理框架（如 vLLM、sglang 等）保持良好的生态兼容，确保作品可在真实的 LLM 生产推理环境下正常部署与测试。
**3、作品提交要求**
本项赛题的参赛团队要求完成一个或多个，最终评奖将依据完成的赛题数量和质量进行综合评选。赛事作品须按照以下提交模式（三选一）提交才能被纳入最终的评审，本赛事对应开源项目地址：https://github.com/kvcache-ai/Mooncake
根据赛题详情页面编写作品提交要求，提交模式（三选一）：
- 文件 + 链接：文件≤150MB，格式不限
- 仅提交压缩包：文件≤1GB，格式不限
- 提交PR（pull request）给开源项目
**必含成果**
- 5分钟内作品展示视频、方案文档 / PPT、源代码
- 所有成果必须托管至 github平台开源，否则取消评审资格
**4、提交时间**
- 初赛：2026.3.20-7.10（平台提交）
- 决赛：2026.8.3-8.6（邮箱 osic@ccf.org.cn 提交）
**5、核心赛程**
1. 报名 + 初赛提交：2026.3.20-7.10
2. 初赛评审：2026.7.11-7.15（评出三等奖 + 决赛候选）
3. 决赛提交：2026.8.3-8.6
4. 线下决赛：2026.8.9-8.10（重庆，答辩≤20 分钟）
5. 结果公示：2026.8.11-8.15
6. 颁奖典礼：2026.8.16（重庆 CCF 开源大会）
**评审标准**
| 评分项 | 权重 |
| ------------ | ------------ |
| 技术完整性 | 30% |
| 开源规范性 | 10% |
| 场景适配性 | 25% |
| 创新性 | 35% |
**核心规则：**
参赛作品必须为原创，不得侵犯任何第三方的知识产权。若使用开源代码，必须遵守其开源许可协议，并在文档中明确声明来源、协议和依赖关系。为保障赛事奖项设置的科学性与参赛选手的积极性，若赛题报名人数不足，组委会将根据赛事评审结果统筹评定奖项。
